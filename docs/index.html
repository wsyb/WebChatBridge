FAQ

What browsers are supported?
Any Chromium-based browser: Chrome, Edge, Brave, etc.
Is it safe?
The extension only runs when you activate it. It reads AI responses from the page and sends commands to a local process on your machine. No data is sent to external servers.
Which AI platforms are supported?
DeepSeek, Kimi, and Doubao. More platforms may be added in the future.
How does it work?
The Chrome extension detects tool call blocks in AI responses, sends them to a local native host process, which executes the commands and returns results back to the chat.
