快速开始

三步完成安装

1

下载并编译 Native Host

克隆仓库，运行安装脚本：cd native-host && bash install.sh

2

安装 Chrome 扩展

打开 chrome://extensions/，启用开发者模式，加载已解压的扩展程序

3

开始使用

打开 AI 聊天页面，点击工具栏的「注入提示词」，然后告诉 AI 你想做什么
